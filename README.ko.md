# PixelRPG

[English](README.md) | 한국어

언리얼 엔진 5.8로 만든 3D 픽셀아트 액션 RPG 프로토타입입니다. 버텍스 컬러를 입힌 로우폴리 모델을 픽셀아트로 렌더링하고, 게임플레이 어빌리티 시스템(GAS) 기반의 근접 전투, 마법사 동료, 채집, 마을 브룩홀로우의 퀘스트 6개, 세이브 기능이 들어 있습니다.

## 구성

- `Source/PixelRPG`: C++ 게임플레이 코드 (전투, 카메라 리그와 픽셀 포스트 프로세스, HUD, 오디오, 퀘스트, 인벤토리).
- `Tools/make_assets_blender.py`: Blender로 모든 모델을 만들어 `SourceArt/*.fbx`로 내보냅니다.
- `Tools/make_textures.py`: 디테일, 폴리지, 지형 색상 텍스처를 생성합니다 (Pillow 필요).
- `Tools/setup_pixel_assets.py`: 전부 언리얼로 임포트하고, 머티리얼과 `PixelTest` 레벨(랜드스케이프 포함)을 만듭니다.
- `Tools/rebuild_and_shot.sh`: 모듈을 빌드하고, 에셋 셋업을 돌리고, 게임을 실행해 `Saved/PixelShot.png`에 스크린샷을 저장합니다.

## 게임 내용

- 퀘스트: 첫 걸음 → 강철과 짚단 → 대장간의 구리(창 해금), 마법의 불꽃(동료), 짓밟힌 정원, 마지막으로 공터의 왕(보스 슬라임 킹). 퀘스트 내용은 `Source/PixelRPG/World/PixelQuestCatalog.cpp` 한 곳에 있습니다.
- 몬스터: 슬라임(몸통 박치기), 버섯 몬스터(멀리서 달릴수록 빨라지는 돌진, 벽에 부딪히면 기절), 바위 몬스터(굴러서 돌진하거나 몸통 박치기, 체력이 높고 잘 밀리지 않음). 계곡 곳곳에 캠프로 배치되고, 한 번에 싸우는 적은 최대 5마리입니다.
- 몬스터 모델은 스켈레탈 메시가 아니라 포즈별 스태틱 메시 7개(`SM_<이름>_00`~`_06`)를 번갈아 보여 주는 플립북 방식입니다.

## 조작

- 이동 `WASD`, 공격 `마우스 왼쪽` / `J`, 회피 `Space`, 무기 교체 `Tab` / `R`
- 동료: 탑승·내리기 `G`, 따라오기·대기·집중 `1` / `2` / `3`, 자동 모드 `T`, 볼트 `F`, 강화 `C`
- 상호작용(채집, 대화) `E`, 저장 `F5`, 불러오기 `F9`
- 카메라: 마우스로 회전, 줌 `Z` / `X`, 3인칭·탑다운 전환 `V` (탑다운에서는 `←` / `→`로 회전), 픽셀 효과 켜기·끄기 `F1`
- 마우스 감도 `[` / `]`, 화면 아래 조작법 숨기기·보이기 `H` (둘 다 저장됨)

검 공격을 이어서 누르면 내려베기, 가로베기, 역베기, 올려베기, 찌르기 순서의 5연속 콤보가 나갑니다.

## 자동 테스트

- `-PixelQuestTest`: 퀘스트 6개를 자동으로 끝까지 진행합니다. `-PixelCombatTest`: 근처 적과 자동으로 싸웁니다.
- `-PixelNewGame`: 기존 세이브를 지우고 새로 시작, `-PixelSaveSlot=<이름>`: 다른 세이브 슬롯 사용.

## 사운드

효과음은 구매한 마켓플레이스 팩을 사용하며, 이 저장소에는 포함되어 있지 않습니다 (`Content/Dev`는 무시됩니다). 팩이 없으면 게임은 소리 없이 실행됩니다. 필요한 파일 목록은 `Source/PixelRPG/PixelAudio.cpp`에 있습니다.

## 대용량 파일

`.uasset`, `.umap`, `.fbx`, `.png` 파일은 Git LFS로 저장됩니다. 클론하기 전에 `git lfs install`을 실행하세요.
